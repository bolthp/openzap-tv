# CLAUDE.md

## Project

`openzap` — Rust binary crate (edition 2024), currently a skeleton with no dependencies.

## Layout

- `src/main.rs` — entry point
- `Cargo.toml` — crate manifest

## Commands

- Build: `cargo build`
- Run: `cargo run`
- Test: `cargo test`
- Lint: `cargo clippy`
- Format: `cargo fmt`

## Conventions

- Keep code formatted with `cargo fmt` and clippy-clean before committing.
- Add dependencies deliberately; the project currently has none.
